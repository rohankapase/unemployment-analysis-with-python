# Unemployment Analysis in India (2020)

### Project Overview

This project provides a comprehensive analysis of the unemployment rate in India during the year 2020. Using Python and data science libraries, it visualizes the sharp economic impact of the COVID-19 national lockdown, identifying regional trends and high-impact zones across different Indian states.

### Key Objectives

* **Analyze** the spike in unemployment during the 2020 lockdown period.
* **Visualize** regional disparities using interactive geospatial maps.
* **Identify** states with the highest and lowest labor participation rates.

### Tech Stack

* **Language:** Python 3.x
* **Libraries:** * `Pandas` (Data manipulation)
* `Matplotlib` & `Seaborn` (Static plotting)
* `Plotly` (Interactive maps & animations)



### Project Structure

1. **Data Cleaning:** Standardization of column names and date formatting.
2. **EDA (Exploratory Data Analysis):** Statistical summary of unemployment and employment figures.
3. **Trend Visualization:** Time-series charts showing the unemployment peak in April-May 2020.
4. **Geospatial Mapping:** An animated bubble map showing state-wise data based on latitude and longitude.

### How to Run

1. Clone this repository:
```bash
git clone https://github.com/rohankapase/unemployment-analysis-with-python.git

```


2. Install dependencies:
```bash
pip install pandas matplotlib seaborn plotly

```


3. Run the script:
```bash
python unemployment_analysis.py

```



### Key Insights

* **Peak Crisis:** Unemployment reached record highs in April and May 2020 due to the strict national lockdown.
* **State Impact:** States like Haryana, Bihar, and Jharkhand recorded some of the highest unemployment rates during the pandemic.
* **Visual Clarity:** The interactive map allows users to see the "heat" of unemployment move across the country month-by-month.

### Dataset

The data used in this project includes monthly unemployment rates, employment counts, and labor participation rates for all Indian states, along with geographical coordinates for mapping.
